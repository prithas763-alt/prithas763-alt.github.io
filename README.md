# Pritha Sharma | Academic Website

Personal academic homepage for Pritha Sharma, B.Sc. (Hons.) Forensic Science with Research, Lovely Professional University (2026-2030).

Static site (HTML, CSS, JavaScript), no build step.

- LinkedIn: https://www.linkedin.com/in/pritha-sharma-7a32aa447
- CV: `assets/Pritha_Sharma_CV.pdf`

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Publish with GitHub Pages

1. Create a repository named `pritha-sharma.github.io` (use `<your-github-username>.github.io` for a root address) or any name for a project site.
2. Upload all files in this folder (`index.html`, `style.css`, `script.js`, `assets/`, `README.md`).
3. In the repository go to **Settings > Pages**, set **Source** to *Deploy from a branch*, choose **main** and **/ (root)**, then Save.
4. After about a minute the site is live at `https://<your-github-username>.github.io/` (or `/<repo-name>/` for a project site).
